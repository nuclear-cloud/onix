# Yakaboo Scraper Module

Цей модуль відповідає за отримання, розбір (parsing) та трансформацію даних з формату Yakaboo (JSON) у внутрішній формат системи (ONIX/Catalog/Market).

## Структура файлів

| Файл | Призначення |
|---|---|
| **`settings.py`** | ⚙️ **Налаштування**. Константи, префікси ID (`yakaboo_`), коди валют за замовчуванням. |
| **`mapper.py`** | 🗺️ **Словники**. Правила перекладу значень Yakaboo у коди ONIX (напр. "Тверда" -> "BB"). |
| **`extractor.py`** | ⛏️ **Видобуток**. Низькорівневі функції для "викопування" чистих даних з брудного JSON (очистка HTML, пошук в `*_label`). |
| **`skeleton_transformer.py`** | 💀 **Скелет**. Швидкий трансформер для Кроку 1. Створює мінімальний об'єкт (ISBN, Title, Price). |
| **`enrichment_transformer.py`** | 💎 **Збагачення**. Повний трансформер для Кроку 2. Створює повний ONIX об'єкт (Authors, Subjects, Descriptions). |
| **`DATA_STRUCTURE.md`** | 📄 Довідник полів оригінального файлу Yakaboo. |

## Потік даних (Pipeline)

1.  **Raw JSON** потрапляє в систему.
2.  **Extractor** витягує чисті значення (напр. ціну як `float`, авторів як список рядків).
3.  **Mapper** перетворює текстові значення (напр. "Англійська") у коди (ONIX `eng`).
4.  **Transformer** (Skeleton або Enrichment) збирає це все у Pydantic-модель.
5.  **Loader** (в `scripts/`) записує модель у PostgreSQL.
